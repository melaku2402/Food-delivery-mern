👍 🍔 Food Delivery Web App

A modern, responsive MERN Stack Food Delivery Application that allows users to browse food items, place orders, manage their cart, and securely authenticate. The application also includes a powerful admin dashboard for managing products, customers, and orders.

 ✨ Features

👍 Customer

- Secure User Authentication (JWT)
- Browse Food Menu
- Search & Filter Foods
- Shopping Cart
- Online Order Placement
- Order History
- Responsive Design
- Fast & User-Friendly Interface

👍 Admin

- Secure Admin Login
- Dashboard Analytics
- Add, Edit & Delete Food Items
- Upload Food Images
- Manage Orders
- Update Order Status
- Inventory Management

 🛠 Tech Stack

| Category | Technology |
|----------|------------|
| Frontend | React.js, CSS3, Axios |
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose |
| Authentication | JWT, bcrypt.js |
| File Upload | Multer |
| Payment | Stripe |
| Version Control | Git & GitHub |

 🚀 Installation

Clone the repository

bash
git clone https://github.com/yourusername/Food-Delivery-web-App.git


Go to the project folder

bash
cd Food-Delivery-web-App


Install dependencies

👍 Backend

bash
cd backend
npm install

👍 Frontend

bash
cd frontend
npm install


👍 Admin

bash
cd admin
npm install


 ⚙️ Environment Variables

Create a `.env` file inside the backend folder.

env
PORT=4000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
STRIPE_SECRET_KEY=your_stripe_secret_key


 ▶️ Run the Application

Backend

bash
cd backend
npm run server


Frontend

bash
cd frontend
npm run dev


Admin

bash
cd admin
npm run dev
